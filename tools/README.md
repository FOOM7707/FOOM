# tools — 업무용 도구

**이 폴더는 서비스 코드가 아닙니다.** 품(FOOM) 서비스에 들어가지 않고, 빌드·배포·테스트에도 포함되지 않습니다. 팀이 진행 상황을 보고 관리하는 데 쓰는 파일만 둡니다.

프로젝트 코드는 `src/`(화면)와 `functions/`(서버)에 있습니다. 설계 문서는 `docs/`입니다.

---

## 개발현황판.html

스프린트 9단계의 **계획 대비 실제 진행 상황**을 한 화면에서 봅니다.

### 어떻게 여나

**내려받아 두 번 누르면 열립니다.** 설치할 것도, 서버를 띄울 것도 없습니다. 인터넷이 연결돼 있으면 글꼴을 받아와 더 보기 좋습니다(끊겨 있어도 내용은 다 보입니다).

### 무엇이 보이나

- **요약 4칸** — 전체 진행률 / 현재 단계 / 개발 기간 / 자동 점검 수
- **전체 일정** — 9단계를 8~12월 축에 막대로. 채워진 부분이 완료된 만큼이고, 오늘 위치가 세로선으로 표시됩니다. 막대를 누르면 그 단계 항목이 열립니다
- **단계별 작업** — 항목마다 **완료 / 진행 중 / 막힘 / 미착수** 상태와 **왜 그 상태인지** 한 줄
- **바뀐 기록** — 누가 언제 어떤 항목의 상태를 바꿨는지 최근 12건
- **외부에서 풀어야 하는 것** — 계약·심사처럼 개발로는 해결되지 않는 항목
- **작업량 추이** — 날짜별 변경 묶음 수

찾기(검색), 상태·영역별 걸러 보기, 모두 펼치기·접기, 화면 밝기 바꾸기가 됩니다. 인쇄하면 A4에 맞게 나옵니다.

### ⚠️ 내려받은 파일은 「보기 전용」입니다

상태를 눌러 **바꾸려면 공유 링크로 열어야 합니다.** 내려받은 파일에서는 상태 표시가 눌리지 않고, 화면 위쪽에 그 이유가 안내됩니다(고장이 아닙니다).

| | 내려받은 파일 | 공유 링크 |
|---|---|---|
| 보기 | O | O |
| 인쇄 | O | O |
| 상태 바꾸기 | **X** | O (편집 권한 필요) |
| 팀원과 공유 | X — 각자의 사본 | O — 저장하면 모두의 화면에 반영 |

**공유 링크는 팀 안에서 따로 안내합니다.** 링크로 초대받을 때 **「편집」 권한**을 받아야 상태를 바꿀 수 있습니다 — 보기 권한만 받으면 내려받은 파일과 같습니다.

### 내용은 어떻게 갱신되나

**두 가지가 서로 다릅니다.**

1. **항목 상태**(완료·진행 중 등) — 공유 링크에서 팀원이 직접 눌러 바꾸고 「팀에 저장」을 누르면 모두에게 반영됩니다
2. **계획 항목·기간·작업량 수치** — 아직 **수동**입니다. 파일 안의 상태 데이터 한 곳(`<script id="state">`)에 모여 있어 그것만 고치면 진행률·타임라인·요약이 모두 따라 바뀝니다

매일 아침 문서·저장소·노션을 읽어 자동으로 맞추는 방식은 **다음 단계**입니다. 다만 「진행률을 기계가 판정하는 것」은 신뢰도가 낮아서(변경 하나가 항목 절반일 수도, 세 항목에 걸칠 수도 있음), **셀 수 있는 것만 자동으로 채우고 항목 상태는 사람이 표시하는** 방식을 검토 중입니다.

### 진행률은 어떻게 계산하나

계획 항목 수를 기준으로 **완료 1점, 진행 중 0.5점, 미착수·막힘 0점**입니다. **작업량이나 난이도를 반영한 값이 아닙니다** — 「공정률 37%」처럼 읽지 마세요.

### 이 파일을 고칠 때

`tools/개발현황판.html`은 발행본과 같은 코드로 **생성한 사본**입니다. 내용을 바꿀 일이 있으면 파일을 직접 고치기보다 담당자에게 알려주세요 — 발행본과 저장소 사본이 어긋나면 어느 쪽이 맞는지 알 수 없게 됩니다.
