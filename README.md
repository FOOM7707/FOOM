# FOOM

품(FOOM) 사업 이해 종합 정리
앱 이름 & 콘셉트
"품"은 가칭으로 품다 / 숲의 공간 / 품는다는 중의적 의미를 담고 있습니다.
핵심 정의: 도시 근교에서 산림복지 프리랜서 전문가와 일반 이용자를 연결하는 중개 기반 마켓플레이스
기존 플랫폼(자연휴양림·치유센터)은 시골·숙박 중심
팔달산처럼 도심 가까운 숲에서 하는 지역 프로그램 타겟
이 영역을 특화한 민간 플랫폼은 현재 존재하지 않음 (공백 시장)
벤치마킹 분석
마인드카페, 숨고— 핵심 참고 모델
심리상담사 프로필·가격·후기를 보고 온/오프라인 상담을 예약하는 구조.
자격증 검증 + 이용자 리뷰 기반 신뢰 체계 구축
B2C 수익 한계 → 기업(B2B) 계약 700건 이상으로 수익화 성공
품도 동일한 B2B 전환 경로를 따라야 함
심리학이 산림복지와 겹치는 부분이 많아 모델 적용성 높음
에어비앤비 체험·프립·클래스101
체험 마켓플레이스 구조 참고. 그러나 클래스101·스크립 등 B2C 체험 플랫폼들은 대부분 구조조정 상황 → B2C 단독으로는 지속 불가
간병인 중개 플랫폼
흩어진 전문가를 플랫폼으로 모아 검증된 매칭 제공 → 연매출 400억까지 성장. 단, 간병은 수요가 훨씬 긴박하므로 품은 그 수준은 기대하기 어려움.
숭고
지역 기반 전문가 연결 구조가 품과 유사. 참고 대상.

리스크: 플랫폼이 생겼다고 비활동자들이 갑자기 움직일 가능성 낮음. 초기 공급자 모집은 현재 활동 중인 전문가 중심으로 접근 필요.
기회: 지자체 용역 최저임금 구조에 경력자 불만 팽배 → 플랫폼으로 더 많이 벌 수 있는 구조가 핵심 가치. 이용자들의 "숲 체험은 공짜" 인식을 여행·고급 체험 형태로 전환 필요.
법률 리스크 (Sprint 0 블로커)
① 프리랜서 단독 활동 가능 여부 ⚡ 최우선
산림복지전문업 사업자 등록에는 자격증 보유자 3인 이상이 필요. 그러나 자격증 있는 개인이 사업자 등록 없이 프리랜서로 플랫폼에서 활동하고 개인 소득으로 신고하는 방식은 법적으로 문제없을 것으로 추정됨(강사 프리랜서 구조와 동일). 산림청 유권해석으로 반드시 확인 필요. 앱의 회원가입 필드와 정산 구조가 여기에 달려 있음.
② 바우처 결제 구조
산림복지 바우처는 국민카드 단말기로 현장 직접 집행 → 플랫폼 중간 수수료 불가. 바우처 이용자 대상으로는 광고비·노출비 모델로 전환 필요. 한국산림복지진흥원에 연동 가능성 별도 문의.
③ 약관 & 개인정보처리방침
공정위 면책조항 금지 기준 반영하여 법무 검토 필요.
수익 모델 구조
PG사 수수료 3~3.5% → 수수료 10% 설정 시 실수익 약 6.5% 수준. 부가세 고려하면 B2C 수수료만으로는 수익이 빈약함.
3단계 수익 구조
1단계 — B2C (데이터 축적 목적)
수수료 수익보다 플랫폼 신뢰도·데이터 축적이 목적
그룹 프로그램으로 단가 낮춰 접근성 제고
1:1 프리미엄 프로그램 병행
2단계 — B2B (핵심 수익원)
기업 직원 복지(EAP) 예산 활용
마인드카페가 심리상담으로 기업 700건 계약한 경로 동일 적용
산림복지 효과는 학계 논문으로 검증됨
3단계 — B2G (지자체·정부)
B2C 실적·데이터 → 지자체 위탁사업·바우처 연동 영업 자료
산림복지진흥원 보건소 프로그램 입찰 경로
