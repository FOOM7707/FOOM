## 1. 스프린트 로드맵 (2주 단위, 8/17 월요일부터)

### Sprint 1 — 8/17(월) ~ 8/30(일): 인증 + 프로그램 등록
- **<백엔드>** 인증 API 완성 (`POST /auth/signup`, `POST /auth/provider/apply`), `programs` CRUD API, 관리자 심사(승인/반려) 플로우
- **<프론트엔드>** 로그인 화면, 프로그램 등록/조회 화면(mock 데이터 기반), 디자인 고정밀화 착수 (와이어프레임 v2 + 토스 미니앱 스타일 참고)

### Sprint 2 — 8/31(월) ~ 9/13(일): 스케줄 생성 + 검색
- **<백엔드>** `scheduleTemplates → schedules` 자동 생성(Scheduled Function, 8주 롤링 윈도우), 최소인원 미달 자동취소(`checkMinCapacity`), 위치 기반 검색(geohash)
- **<프론트엔드>** 검색/탐색 화면(지역·날짜·가격 필터), 프로그램 상세 화면

### Sprint 3 — 9/14(월) ~ 9/27(일): 예약·결제 (동시성 핵심 구간)
- **<백엔드>** 예약 홀드 로직(`pending_payment`+`expiresAt`), 결제 웹훅 멱등처리, `releaseExpiredHolds` 스케줄 함수
- **<프론트엔드>** 예약/결제 화면, 토스페이먼츠+포트원 결제창 연동

### Sprint 4 — 9/28(월) ~ 10/11(일): 취소·환불 + 공급자 페널티
- **<백엔드>** 취소/환불 API(진행일 기준 환불정책 로직), 공급자 페널티 구현(경고 누적 → 활동 제한, `violations` 기록)
- **<프론트엔드>** 예약 취소 화면, 마이페이지(예약내역·취소내역)

### Sprint 5 — 10/12(월) ~ 10/25(일): 리뷰·문의·정산
- **<백엔드>** 리뷰 API, 1:1 문의 API + 알림톡 트리거, 정산(`settlements`/`settlementItems`) API
- **<프론트엔드>** 리뷰 작성/조회 화면, 1:1 문의 화면

### Sprint 6 — 10/26(월) ~ 11/8(일): 관리자 페이지 + mock→실제 전환
- **<백엔드>** 관리자 API(공급자 승인/프로그램 심사/정산 지급) 마무리
- **<프론트엔드>** 관리자 대시보드 화면, 프론트 mock 데이터를 실제 API로 전면 교체

### Sprint 7 — 11/9(월) ~ 11/22(일): 통합 테스트 + QA
- **<공통>** 전체 플로우 통합 테스트(회원가입→예약→결제→리뷰→정산), 버그 픽스, 보안규칙 점검

### Sprint 8 — 11/23(월) ~ 12/6(일): 베타 오픈 준비
- **<공통>** 성능 테스트, 알림톡/SMS 실제 발송 테스트, 소규모 베타(내부/지인) 오픈

### Sprint 9 — 12/7(월) ~ 12/20(일): 정식 오픈 대응 및 안정화
- **<공통>** 베타 피드백 반영, 최종 QA, 정식 오픈, 에러 모니터링/로그 수집 셋업

### 연말 버퍼 — 12/21(월) ~ 12/31(목)
